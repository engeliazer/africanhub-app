Getting Started with OCPAC

Welcome to the Online CPA Review Classes Management System (OCPAC). This guide will help you navigate and use the system effectively based on your role and permissions.

Logging In

  1. Visit https://app.ocpac.dcrc.ac.tz in your web browser
  2. Enter your username and password in the login form
  3. Click the "Login" button to access your account
  4. Upon successful login, you'll be directed to your dashboard
Note: If you've forgotten your password, use the "Forgot Password" link on the login page to reset it.

Navigating the System

The OCPAC system has a user-friendly interface with the following main components:

  • Top Navigation Bar: Contains the system logo, module selector, role selector, and user profile menu
  • Sidebar: Displays menu items based on your role and permissions
  • Main Content Area: Shows the content of the selected menu item
  • Breadcrumb: Helps you track your location within the system
Tip: You can collapse the sidebar by clicking the toggle button at the top of the sidebar to get more screen space.

Understanding User Roles

The OCPAC system uses role-based access control to manage user permissions. Each user is assigned one or more roles, which determine what they can access and do within the system.

System Administrator (SYSADMIN)

System Administrators have full access to all features and functionalities of the OCPAC system. They can:

  • Manage all user accounts and roles
  • Configure system settings
  • Access all modules and features
  • Manage support and chat functionality
  • View and generate all reports

Support Staff

Support staff members can:

  • Access the support module
  • Respond to user inquiries
  • View user information
  • Generate support reports

Facilitator

Facilitators can:

  • Access the facilitation module
  • Manage study materials
  • Track student progress
  • Generate facilitation reports

Student

Students are the primary users of the OCPAC system. They can:

  • View their dashboard
  • Access study materials
  • Submit assignments
  • Track their progress
  • Access support when needed

Accountant

Accountants can:

  • Access the accounting module
  • Manage financial transactions
  • Generate financial reports
  • Track payments and invoices
Tip: You can switch between roles using the role selector in the top navigation bar if you have multiple roles assigned to your account.

Managing Applications

The Applications module allows you to manage student applications for CPA review classes.

For Students

  1. Navigate to the Applications module
  2. Click on "New Application" to start a new application
  3. Fill in all required information in the application form
  4. Upload any necessary documents
  5. Submit your application
  6. Track the status of your application in the "My Applications" section

For Administrators

  1. Navigate to the Applications module
  2. View all applications in the "All Applications" section
  3. Filter applications by status, date, or other criteria
  4. Click on an application to view details
  5. Update the application status (Pending, Approved, Rejected)
  6. Add notes or comments to the application
  7. Generate application reports as needed
Note: Applications go through a review process before being approved or rejected. This process may take several business days.

Accessing Study Materials

The Study Materials module provides access to all learning resources for CPA review classes.

Finding Study Materials

  1. Navigate to the Study Materials module
  2. Browse materials by subject, topic, or type
  3. Use the search function to find specific materials
  4. Click on a material to view or download it

Types of Study Materials

  • Lecture Notes: Comprehensive notes for each topic
  • Video Lectures: Recorded lectures from facilitators
  • Practice Questions: Questions to test your understanding
  • Past Papers: Previous exam papers for practice
  • Study Guides: Structured guides for exam preparation
Tip: Download materials for offline access when you have a stable internet connection.

Facilitation Management

The Facilitation module helps manage the teaching and learning process for CPA review classes.

For Facilitators

  1. Navigate to the Facilitation module
  2. View your assigned classes and students
  3. Upload and manage study materials
  4. Schedule and manage online sessions
  5. Track student attendance and participation
  6. Provide feedback on student assignments
  7. Generate facilitation reports

For Students

  1. Navigate to the Facilitation module
  2. View your class schedule
  3. Join online sessions at the scheduled time
  4. Submit assignments and view feedback
  5. Track your attendance and participation
Note: Online sessions are conducted through the integrated video conferencing tool. Make sure your device has a working camera and microphone.

Getting Support

The Support module provides assistance for users experiencing issues or with questions about the OCPAC system.

For Students

  1. Navigate to the Support module
  2. Click on "New Support Request"
  3. Select the category of your issue
  4. Provide a detailed description of your problem
  5. Attach any relevant screenshots or files
  6. Submit your request
  7. Track the status of your request in the "My Requests" section

For Support Staff

  1. Navigate to the Support module
  2. View all support requests in the "All Requests" section
  3. Filter requests by status, priority, or category
  4. Click on a request to view details
  5. Respond to the request with a solution or additional questions
  6. Update the request status (Open, In Progress, Resolved)
  7. Generate support reports as needed
Tip: For urgent issues, use the chat feature in the bottom right corner of the screen for immediate assistance.

Accounting Features

The Accounting module manages financial transactions related to CPA review classes.

For Accountants

  1. Navigate to the Accounting module
  2. View financial dashboard with key metrics
  3. Manage invoices and payments
  4. Track student fees and payments
  5. Generate financial reports
  6. Reconcile accounts

For Students

  1. Navigate to the Accounting module
  2. View your payment history
  3. Download invoices and receipts
  4. Make payments for classes
  5. View your financial statements
Note: All financial transactions are securely processed and recorded in the system.

Generating Reports

The Reports module allows you to generate various reports based on your role and permissions.

Available Reports

  • Application Reports: Track application status and statistics
  • Student Reports: View student enrollment and progress
  • Facilitation Reports: Monitor teaching and learning activities
  • Financial Reports: Track revenue, expenses, and financial metrics
  • Support Reports: Analyze support requests and resolution times

Generating a Report

  1. Navigate to the Reports module
  2. Select the type of report you want to generate
  3. Set the parameters for the report (date range, filters, etc.)
  4. Click "Generate Report"
  5. View the report in the browser
  6. Download the report in your preferred format (PDF, Excel, etc.)
Tip: You can schedule reports to be automatically generated and emailed to you at regular intervals.
